Submit your result

Run the Score preset (or Standard) on AC power with Windows set to Best performance, save the results, and attach the .toon.txt file to a result submission issue. Accepted runs are added to library/ and appear here and in the app.

How the score works

Each input is a ratio to the reference run (inverted for latency and frame time), each component a weighted geometric mean, Overall a weighted geometric mean of the components. The app's "About the score" page lists every input and weight. Runs flagged (battery, throttling, non-default settings...) are shown, not hidden.
